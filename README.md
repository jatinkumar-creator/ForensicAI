
# ForensicAI

**Agentic AI Digital Forensics Investigation Assistant**

ForensicAI is a modular, local-first digital forensics investigation support platform designed to assist forensic investigators with evidence management, artifact analysis, timeline reconstruction, geospatial analysis, pattern detection, and AI-assisted investigations.

## Project Objectives

- Evidence ingestion and format identification
- SHA-256 evidence integrity verification
- Digital forensic artifact extraction
- Android, iOS, and computer artifact analysis
- UFDR report parsing using publicly available compatible tools
- Timeline reconstruction
- Geospatial intelligence
- Machine learning-based pattern analysis
- Retrieval-Augmented Generation (RAG)
- Multi-agent AI workflows using LangGraph
- Source-linked forensic report generation

## Technology Stack

- Python
- Jupyter Notebook
- Streamlit
- Pandas and NumPy
- Scikit-learn
- LangChain and LangGraph
- FastAPI
- SQLite
- Git and GitHub

## Development Principles

- Local-first processing
- Evidence integrity preservation
- Read-only handling of original evidence
- Source traceability
- Human-supervised AI analysis
- Open-source and zero-additional-cost development

## Project Status

Currently in the foundation and environment setup phase.

## Disclaimer

ForensicAI is an experimental forensic investigation support project. It does not replace validated forensic acquisition tools, qualified forensic examination, or independent verification by an investigator.
